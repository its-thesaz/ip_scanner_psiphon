## 🇮🇷 فارسی

### 🚀 معرفی

**پنل پیشرفته شبکه شیر و خورشید** یک ابزار تحت وب **حرفه‌ای**، **سریع** و **کاملاً آفلاین** است که سه ابزار قدرتمند را در یک پنل یکپارچه گرد هم آورده است:

1. **🔍 اسکنر IP شیر و خورشید** – اسکن هوشمند آی‌پی‌ها، رنج‌های CIDR و بازه‌های IP با سه حالت **دستی**، **آماده** و **خودکار**
2. **🔐 تست اختصاصی SNI** – بررسی آی‌پی‌ها بر روی یک دامنه (SNI) خاص جهت اطمینان از عبور هدر TLS
3. **🌐 تست پروکسی سایفون (Psiphon)** – تحلیل و ارزیابی پروکسی‌های سایفون با فرمت منعطف

همه‌ی پردازش‌ها در مرورگر شما انجام می‌شود و **هیچ داده‌ای به سرور ارسال نمی‌شود**. این ابزار توسط **THE SAZ** و تیم توسعه‌دهندگان با همکاری کانال **@InfoTech_VK** طراحی و پیاده‌سازی شده است.

### 🧠 موتور اسکن (چطور کار می‌کند؟)

- **اسکنر IP**: با استفاده از درخواست‌های HTTPS `no-cors` و تصویرنگاری مخفی (`/favicon.ico`)، پاسخ‌گویی هر آی‌پی را بررسی می‌کند.
- **تست SNI**: آی‌پی‌ها را با هدر SNI دلخواه تست می‌کند تا از تطابق هدر TLS اطمینان حاصل کند.
- **تست سایفون**: پروکسی‌های وارد شده را به‌صورت هوشمند پارس کرده و با شبیه‌سازی اتصال از طریق پروکسی به سایت هدف، پینگ عبوری را اندازه‌گیری می‌کند.
- **همزمانی**: با استفاده از `Promise.all` و تکنیک **Pooling**، درخواست‌ها را به‌صورت هم‌زمان با تعداد ترد قابل تنظیم ارسال می‌کند.
- **تایم‌اوت پویا**: زمان انتظار برای هر درخواست را بر اساس تنظیمات کاربر مدیریت می‌کند.

---

### 🖥️ نحوه‌ی استفاده (گام‌به‌گام)

1. فایل `index.html` را در مرورگر خود باز کنید.
2. با استفاده از تب‌های بالای صفحه، ابزار مورد نظر را انتخاب کنید:
   - **اسکنر IP** → برای اسکن آی‌پی‌ها و رنج‌های شبکه
   - **تست SNI** → برای تست آی‌پی‌ها روی یک دامنه خاص
   - **تست سایفون** → برای ارزیابی پروکسی‌های Psiphon
3. **در اسکنر IP**، یکی از سه حالت را انتخاب کنید:
   - **دستی**: آی‌پی‌ها، CIDR یا بازه‌ها را مستقیماً وارد کنید یا فایل TXT بارگذاری کنید.
   - **آماده**: از لیست رنج‌های آماده‌ی Akamai انتخاب کنید و به سبد تست اضافه کنید.
   - **خودکار**: سیستم به‌صورت هوشمند رنج‌های تصادفی از پایگاه‌داده انتخاب می‌کند.
4. **در تست SNI**، دامنه‌ی هدف (SNI) و لیست آی‌پی‌های مورد نظر را وارد کنید.
5. **در تست سایفون**، لیست پروکسی‌ها را با فرمت `Host: IP` و `Port: PORT` یا `IP:PORT` وارد کنید. سایت هدف نیز قابل تنظیم است.
6. با لغزنده‌های **تعداد همزمان**، **تایم‌اوت** و **حداکثر رکوردها**، تنظیمات اسکن را شخصی‌سازی کنید.
7. روی **شروع فرآیند تست** کلیک کنید. جدول و آمار به‌صورت زنده بروزرسانی می‌شوند.
8. در حین اسکن، دکمه‌ی **توقف** را برای لغو عملیات دارید.
9. پس از اتمام، از دکمه‌های **کپی سالم‌ها**، **خروجی TXT** و **خروجی CSV** برای ذخیره‌سازی نتایج استفاده کنید.

## 🇬🇧 English

### 🚀 Introduction

**Lion & Sun Advanced Network Panel** is a professional, fast, and fully offline web‑based tool that brings together three powerful network utilities in one unified panel:

1. **🔍 IP Scanner** – Smart IP scanning with CIDR, ranges, and three modes: Manual, Ready‑to‑use, and Auto
2. **🔐 SNI Tester** – Test IPs against a specific SNI (Server Name Indication) to verify TLS header compliance
3. **🌐 Psiphon Proxy Tester** – Analyze and benchmark Psiphon proxies with flexible input formats

All processing happens locally in your browser – **no data is ever sent to any server**. This tool is designed and developed by **THE SAZ** and the development team in collaboration with **@InfoTech_VK** channel.

---

### ✨ Key Features

| Category | Features |
|----------|----------|
| **📥 IP Scanner** | Three distinct modes: Manual (IP/CIDR/Range entry), Ready (pre‑defined Akamai ranges), Auto (intelligent range selection) |
| **🔌 SNI Tester** | Test IPs against custom SNI header with flexible IP list input |
| **🌐 Psiphon Tester** | Smart parser for Psiphon proxies (Host/Port or IP:Port), benchmark ping via target site |
| **⚡ Scanning Engine** | Concurrent scanning with adjustable threads, timeout, safe stop/cancel mechanism |
| **📊 Live Dashboard** | Results table with status, latency, quality badges, real‑time stats (total, tested, alive, dead, best, avg) |
| **📈 Progress Tracking** | Progress bar, live status updates, incremental result rendering |
| **📤 Export Options** | Copy alive addresses, TXT export, CSV (Excel) export |
| **📂 File Upload** | Upload TXT files containing IP lists in Manual mode |
| **🎨 HUD Design** | Dark theme, glass‑morphism, corner brackets, visual badges, smooth animations |
| **🌍 Bilingual** | Full Persian and English support (UI default is Persian) |
| **🛡️ Privacy** | All operations are client‑side; no data is transmitted |

---

### 🧠 Scanning Engine (How it Works)

- **IP Scanner**: Uses HTTPS `no-cors` requests with hidden image pings (`/favicon.ico`) to check IP responsiveness.
- **SNI Tester**: Tests IPs with a custom SNI header to verify TLS handshake compatibility.
- **Psiphon Tester**: Intelligently parses proxy inputs, simulates connections through proxies to target site, and measures RTT.
- **Concurrency**: Uses `Promise.all` with a pooling technique, allowing configurable thread count.
- **Timeout**: Manages request wait time based on user settings.

---

### 🖥️ How to Use (Step‑by‑Step)

1. Open `index.html` in your browser.
2. Use the main tabs to select a tool:
   - **IP Scanner** → Scan IPs and network ranges
   - **SNI Tester** → Test IPs against a specific domain
   - **Psiphon Tester** → Benchmark Psiphon proxies
3. **In IP Scanner**, choose one of three modes:
   - **Manual**: Enter IPs, CIDR, or ranges directly, or upload a TXT file.
   - **Ready**: Select from pre‑defined Akamai ranges and add to the test basket.
   - **Auto**: The system intelligently selects random ranges from the database.
4. **In SNI Tester**, enter the target domain (SNI) and the list of IPs to test.
5. **In Psiphon Tester**, enter proxies in `Host: IP` + `Port: PORT` or `IP:PORT` format. The target site is also configurable.
6. Adjust **Concurrency**, **Timeout**, and **Max Records** sliders to customise the scan.
7. Click **Start Testing**. The table and stats will update live.
8. Use the **Stop** button to cancel the operation at any time.
9. After completion, use **Copy Alive**, **Export TXT**, or **Export CSV** to save results.

### 🎛️ Advanced Settings

| Setting | Description |
|---------|-------------|
| **Concurrency** | Number of simultaneous requests (default 20, range 1–100) |
| **Timeout** | Maximum wait time per request (default 3000 ms) |
| **Max Records** | Maximum number of IPs to scan (default 256) |
